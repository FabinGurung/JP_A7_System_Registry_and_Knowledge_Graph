    CHAPTER 07 / LIVE FILES & NUMBERED HISTORY

    One live ID.
    Every revision remembered.

    Google Docs, Colab notebooks, Sheets and governed original files keep their permanent original live file ID. Before meaningful edits, save a numbered PRE archive copy. Edit the SAME live ID, validate/read back, then save the matching numbered POST copy. Never substitute an archive copy for the live file.

    ARCHIVE THE VERSION. KEEP THE LIVE ID.
    ONE LIVE SOURCEORIGINAL FILE ID · NEVER REPLACED

    Edit here; retain original links and permissions.

    ARCHIVE COPIES · SEPARATE IDs000001 PRE → 000001 POST → 000002 PRE → 000002 POST

    Version the archive filenames and restore content into the SAME original ID.

    Governed seven-step method

    1. Resolve the original → PRE copy → edit same live ID → validate → POST copy → append version history.

    Google Docs, Colab, Sheets and Git

    Each owner/provider uses its own numbered archive and revision namespace. The original source ID is not a version number.

    Apply this to source subjects governed by their A7/A9 owner version policy. Do not create copies for unrelated Git commits, expose private Drive IDs on public Pages, infer approval, or claim an automated Drive-to-Pages integration exists.
