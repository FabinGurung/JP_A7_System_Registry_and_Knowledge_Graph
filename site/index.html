02 / GOVERNANCE PROTOCOLWho owns what? Explore the single-writer rule.⌄

A7 is a metadata catalogue + service registry + knowledge-graph index. Each peer repository is an independently governed bounded context. A7 holds navigational references, never a second writable copy of a specialist template.
