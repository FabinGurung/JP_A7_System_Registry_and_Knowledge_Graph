How it works

01 · UNDERSTAND

Describe the outcome

Say what you want; attach an existing drawing or data if useful. You should not need to handwrite machine parameters.

02 · RESOLVE

AI checks context

It finds the right source and authority, quotes supplied facts and asks only for genuinely missing information.

03 · NORMALIZE

Validate your facts

Versioned code confirms units, identifiers, files, constraints and source revisions. Unsupported guesses are rejected.

04 · EXECUTE

Use the owning engine

CAD, cost, scheduling, structural analysis, operations, research and study use their own tested software—not one giant generic calculation engine.

05 · VERIFY

Check the results

Automatic tests preserve evidence. Professional engineering, legal or academic approval remains separate where required.

06 · EXPLORE

Show only useful detail

Start with the best view for the task. Tap an item to reveal verified detail, labels, status, warnings and next steps.

07 · TRACE

Reproduce the work

Versioned code, source revisions, canonical inputs, toolchain pins and output hashes make a validated run independently auditable.

What “same result every time” means

AI helps you write or understand a request, but the reproducible part is the deterministic engine with identical validated inputs, source revisions, code commit, runtime settings and dependencies. Different AI interpretations, changed documents or unknown engineering inputs can legitimately change the result.

Source and safety: The AI is an operator, not the authority. Private drawings stay in private sources. Public websites display only approved-safe information. Draft or synthetic content must never look like an issued-for-construction drawing.

For developers and other AI agents

Use the same central contract; don't invent another template or duplicate domain truth. Resolve the owning repository through A7, read its A7_MODULE.json, pin the input/source/version, execute the owning tested engine, and capture output evidence.

A7 owns the standard, identities and routing. Specialist repositories own calculations and operational truth. GitHub runs versioned programs and CI; ChatGPT or other AI interprets the human request but cannot upload its hidden reasoning capabilities as GitHub source.
