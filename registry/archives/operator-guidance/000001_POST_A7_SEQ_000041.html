Humans edit owner Sheets; A7 edits only its own Git source. Never change generated Pages, CSV, JSON or Excel to override a Sheet.

Separate evidence stages

Distinguish prepared commit, executed offline tests, GitHub Actions run, deployed Pages and any independent served-page verification.

Read back and preserve

After validation, snapshot POST and update the manifest plus append-only version history with changes, why, source evidence and rollback.

Open a domain-owner gate for missing engineering or private-library evidence. The historical Main/Local ACK remains open.

How it works

01 · UNDERSTAND

Describe the outcome

Say what you want; attach an existing drawing or data if useful. You should not need to handwrite machine parameters.

02 · RESOLVE

AI checks context

It finds the right source and authority, quotes supplied facts and asks only for genuinely missing information.

03 · NORMALIZE

Validate your facts

Versioned code confirms units, identifiers, files, constraints and source revisions. Unsupported guesses are rejected.

04 · EXECUTE

Use the owning engine

CAD, cost, scheduling, structural analysis, operations, research and study use their own tested software—not one giant generic calculation engine.

05 · VERIFY

Check the results

Automatic tests preserve evidence. Professional engineering, legal or academic approval remains separate where required.

06 · EXPLORE

Show only useful detail

Start with the best view for the task. Tap an item to reveal verified detail, labels, status, warnings and next steps.

07 · TRACE

Reproduce the work

Versioned code, source revisions, canonical inputs, toolchain pins and output hashes make a validated run independently auditable.

What “same result every time” means

AI helps you write or understand a request, but the reproducible part is the deterministic engine with identical validated inputs, source revisions, code commit, runtime settings and dependencies. Different AI interpretations, changed documents or unknown engineering inputs can legitimately change the result.

Source and safety: The AI is an operator, not the authority. Private drawings stay in private sources. Unverified inputs and generated drawings stay labelled DRAFT or HOLD. Public websites display only approved-safe information. Draft or synthetic content must never look like an issued-for-construction drawing.

For developers and other AI agents

Use A7 to locate the actual owner; never treat this historical guide as a specialist's normative template. Resolve the owning repository through A7, read its A7_MODULE.json, pin the input/source/version, execute the owning tested engine, and capture output evidence.

A7 owns cross-repository identities and routing, not specialist template standards. Specialist repositories own calculations and operational truth. GitHub runs versioned programs and CI; ChatGPT or other AI interprets the human request but cannot upload its hidden reasoning capabilities as GitHub source.
